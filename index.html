Claw Casual 개인정보 처리방침

운영: Doll

시행일: 2026-08-20

대상 연령: 13세 이상. Designed for Families가 아닙니다.

Claw Casual(이하 “앱”)은 계정 없이 동작하는 인형뽑기 게임입니다. 이 방침은 앱이 어떤 정보를 다루는지 설명합니다.

1. 수집하는 정보

앱은 계정을 만들지 않으며 이름·이메일·전화번호를 직접 입력받지 않습니다. 뽑기 횟수, 보관함, 기계 설정은 이 기기에만 저장됩니다.

2. 광고

횟수가 없을 때 사용자가 선택한 경우에만 Google AdMob 보상 광고를 표시하고 완료 시 +1회를 제공합니다. Google Mobile Ads SDK는 광고 제공, 분석, 부정 사용 방지를 위해 IP 주소로 추정한 대략적 위치, 앱 실행·탭·동영상 조회 같은 상호작용, 앱 및 SDK 진단 정보, 광고 ID·앱 세트 ID 등 기기 식별자를 자동으로 수집하고 Google과 공유할 수 있습니다. 데이터는 전송 중 TLS로 암호화됩니다. Android 설정에서 광고 ID를 재설정하거나 삭제할 수 있습니다.

3. 보관 기간

기기 저장 데이터는 앱을 삭제하거나 앱 데이터를 지우면 함께 삭제됩니다.

4. 글꼴

화면 글꼴은 Noto Sans KR이며 SIL Open Font License 1.1로 제공합니다.
